# Shape Tracker — Release Downloads

This repository distributes approved Shape Tracker installers and public release metadata only. Commercial development source code, local configurations, customer projects and credentials are not stored here.

Windows preview releases are available under Releases. macOS Apple Silicon packages are being prepared; Intel Mac is deferred.

Check SHA256SUMS.txt before installation. Preview installers may be unsigned; see each release for validation limits and system requirements. Downloading does not grant an editor license or AI credits.
